## Chosen Interaction Model

I chose a keyboard-controlled movement system where the player uses the arrow keys to move around the game board and avoid hazards. I selected this approach because it is simple, familiar, and easy for beginners to learn. Since the game is intended for a coding camp audience, keyboard controls provide an accessible and enjoyable gameplay experience for users of different skill levels.

## Challenge Encountered and Solution

One challenge I encountered was managing the game loop and ensuring that hazards spawned correctly while the difficulty increased over time. Initially, multiple intervals could run simultaneously when restarting the game. I solved this by properly clearing existing intervals before creating new ones, which ensured smooth gameplay and prevented unexpected behavior.
